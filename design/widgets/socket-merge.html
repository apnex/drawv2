Socket merge + alignment — the content model

A node/panel's interior is a per-cell 26px socket grid. The author selects one-or-more sockets → merges them into a content region, places content (text — optional outline — or a glyph), and configures alignment. No recursive nesting; one hull.

label == text (plain text, no outline) · input / button = text + outline (the box sits ON the socket border, never beyond) · glyph = an icon in a single socket.
An input is therefore a composition: a text region (the label) + a text-with-outline region (the value). A form is one panel with several content regions. The merge + align is the author action (the editing UI, deferred); the data is just { merged-span, content, align, outline }.
