How a device shows it is a junction -- mockups (B362)

A router, firewall or vxlan passes routes, so it becomes a junction when three or more links end at it, or when a link is pinned through it. Today the network draws its junction ring -- the same light-blue ring a waypoint junction draws -- over the middle of the device's glyph. Every picture here is the product's own drawing (view mode, which the published SVG now matches); each column changes only the junction mark. A device with one link (an endpoint) and a waypoint junction are shown as controls: no option changes them.
