# draw — deletion consequences

**What this is.** One row per symbol deleted by `docs/spec/COMMIT.md` §7.1–7.3 — 36 rows, no more and no
fewer — each interrogated as hard as an addition: who else touches it, what capability disappears the
moment the row lands, what restores that capability, and where nothing does, the `docs/BACKLOG.md` row and
revival trigger that admit the loss. It is produced **before** CS1 implementation begins (§7.4 `[LOCKED]`).

**Why it exists.** During design one deletion — `app/src/sync.js:264-268` — was premised on a false "nothing
else writes this" and would have permanently broken the Google Slides page binding, reverting every re-push
to a URL without a `#slide=` fragment back to slide 1, with no test anywhere catching it; a deletion table
is the side that ships silently, and this file is the mechanism that makes it audible.

**The contract — four columns, no blanks:**

| Column | Requirement |
|---|---|
| **(a) Readers / writers** | Every other site that reads or writes the symbol, with `file:line`, from an exhaustive grep — not a sample. A symbol with zero other sites states `[V, exhaustive grep: no other reference]`. |
| **(b) Capability lost** | What a user or an agent can do today and cannot do the moment the row lands. "Nothing" is legal only when (a) is empty. |
| **(c) Restored by** | The invariant, guardrail or milestone that restores it, named — `I4`, `GR7`, `CS3` — never "the planner". |
| **(d) Not restored** | If (b) is non-empty and (c) is empty: an explicit `docs/BACKLOG.md` row plus a revival trigger. Silence is a gate failure. |

**GR2 polices it.** `tools/scan-claims.mjs` runs over the whole of this file and over `COMMIT.md` §8: every
data row whose first cell names a symbol in backticks must carry a `[V]`/`[I]`/`[A]` marker, and a `[V]`
must be accompanied by a `path:line` token or an explicit measured / exhaustive / counted / grep form. The
file is re-checked at each milestone close for the rows landing in that milestone. Prose tables in this file
keep backticks out of their first cell so the scanner does not read them as deletions.

**Provenance.** Assembled from four independent traces (store core · server surface · document schema ·
browser), each of which ran its own greps rather than inheriting the spec's citations. Where a trace
falsified a claim in `COMMIT.md`, the row says so and the **Findings** section at the end carries it.
Backlog numbering below is harmonised across the four traces: `docs/BACKLOG.md` ends at **B9**
`[V, docs/BACKLOG.md: 9 rows counted]`, so the rows proposed here are **B10–B16**, in the order they first
appear in this file.
